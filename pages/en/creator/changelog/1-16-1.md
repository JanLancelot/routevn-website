## Changes

- Improved SFX sound cards and the channel picker.
- Improved handling of damaged assets and stalled preview loading.
- Projects with corrupt fonts now load instead of failing.
- Fixed the version prefill in the macOS export dialog.
- Updated the app to use the term "ruby text" consistently.

## Windows

⚠ Breaking change: the exported Windows player now uses a new application identifier. Existing saves are no longer loaded and appear reset. Since the Windows player is still in beta, this is a one-time reset and no save data is lost.

- Fixed the preview close button position below the title bar.

## Android

- Added recoverable local project backups.
- Added a Gallery and File picker choice for uploads.
- Fixed canvas rendering and layout action visibility.

## iOS and iPad

- Fixed audio in fullscreen previews.
- Fixed the fullscreen transform editor respecting the iPad safe area.
